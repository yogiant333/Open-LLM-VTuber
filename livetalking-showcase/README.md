# LiveTalking Showcase

独立竖屏大屏数字人展示页。页面按 9:16 设计：LiveTalking 视频占满竖屏舞台，状态、唤醒词和控制按钮以浮层叠在视频上。

默认连接：

- LiveTalking: `http://127.0.0.1:18010`
- Avatar: `xiaomeng_wav2lip256`
- Open-LLM-VTuber WebSocket: `ws://127.0.0.1:18080/client-ws`

运行：

```powershell
npm install
npm run dev
```

打开：

```text
http://127.0.0.1:3001/
```

构建：

```powershell
npm run build
```
